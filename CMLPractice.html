Cisco Modeling Labs Practice

Information on my work with Cisco Modeling Labs

Project Overview

Once I passed the CCNA, I wanted to keep on practicing what I had learned to make sure my skills didn't get rusty. I also wanted to try out network automation. Initially I continued doing labs on Cisco Packet Tracer, but I learned that it was not suitable for what the industry does. I was told about Cisco Modeling Labs which works with real OS images. In addition, I could also practice my automation skills by deploying Ansible playbooks to configure multiple routers.

Objectives

  • Install Proxmox on a used laptop and open the web UI on another machine
  • Install and run Windows Server 2022 and a Kali Linux Machine
  • Run Cisco Modeling Labs to further my networking knowledge and practice network automation
